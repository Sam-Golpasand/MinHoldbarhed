# MinHoldbarhed

**MinHoldbarhed** is an app that helps users keep track of the expiration dates of their food and other items. The goal is to reduce food waste and help users save money by optimizing their consumption.

## About the Project

MinHoldbarhed makes it easy for users to track the expiration dates of their items. By scanning the barcode of an item, the user can automatically register the product in the app and input or confirm the expiration date. The user can then set reminders to receive notifications when the product is nearing its expiration date.

### Goals

- Reduce food waste
- Save money by optimizing consumption
- Help users better organize their food items

## Features

- **Barcode Scanning:** Quickly register food items by scanning their barcode.
- **Expiration Date Tracking:** Input or confirm the expiration date of products.
- **Reminders:** Receive notifications when a product is nearing its expiration date.
- **User-Friendly Design:** Intuitive design that makes the app easy to use for everyone.
- **Multiple Fridges**: Add and share your list with your household, workplace or dormitory with a shared fridge!

## Getting Started

To get started with the project, ensure you have the following prerequisites:

- **Node.js** (tested on version: `v18.19.1`)
- **npm** for package management

Clone the repository:

```bash
git clone https://github.com/Sam-Golpasand/MinHoldbarhed.git
cd MinHoldbarhed
```

## Installation

Install dependencies by running:

```bash
npm install
```

Fill out .env (copy .env.example)

```bash
cp .env.example .env 
```

## Usage

Run the project locally:

```bash
npx expo
```
